# 本项目真实失败与处理（不虚构）

1. **封面标题缺字（问题㉛）**：drawtext 用 PingFang.ttc 首 face，「战场/对手/队」渲染为豆腐块。处理：改用 libass（subtitles 滤镜）重制封面，抽帧确认无缺字。
2. **G4 目录名违反布局合同（问题㉚）**：产物曾写入自创 `G4-剪辑执行/`，approve 守卫拦截。处理：整目录改名 `G4-剪辑与渲染/` 并回填全部引用。
3. **BGM 注册链哈希漂移（registrationChain failed）**：候选登记文件在 G0 登记后补写 analysisRef，material-pack 记录的哈希不再匹配。处理：重算指针哈希回填 material-pack，链路审计 12/12 通过。
4. **黑帧检测命中 3 段**：27.5–28.0s（暗库剪影）、80.3–81.4s（货舱/发射前暗场）。判定：源片暗场景内容，非编码故障；G4 抽帧已人工确认画面存在。列为警告供人工验收。
5. **重复画面检测器缺失**：无可用检测器，按合同记警告不报通过。
