# 素材包使用步骤

按顺序完成以下动作，不需要编写 Prompt、时间码、哈希、SRT 或剪辑顺序。

1. 复制本模板，并将项目文件夹改为一个稳定的项目编号。
2. 填写 `01_需求说明.md`：讲什么、给谁看、时长、横竖版、希望的感觉、口播与声音、不能说什么。没有口播稿时不要先编写，由 Agent 根据事实依据起草。
3. 将未经剪辑、压缩或加字幕的原始视频、图片、文档放进 `02_原始素材/`。
4. 将产品参数、说明书、认可的文案、网页截图或 PDF 放进 `03_事实依据/`。没有资料时也可先留空，但 Agent 必须把无法确认的表达列为待审，不能编造。
5. 填写 `04_授权说明.md`。不清楚授权时写“待确认”，不要默认可发布。
6. 有参考片时放入或登记在 `05_风格参考/`。参考片只用于提取节奏、版式和动画语言，不会被当成输出素材。
7. 有 logo、色值、字体、禁用表达时放到 `06_品牌资产/`；有明确可用的 BGM 或音效时放到 `07_授权音频/`，并写明许可范围。BGM 必须在 G0 明确选择“已提供 / 后续选择 / 不使用”；没有授权音频不等于默认无 BGM。

随后由 Agent 只做素材包技术登记：验证目录、计算哈希、生成或更新 `material-pack.json`，并报告缺失或冲突项。媒体探测以及脚本、镜头、剪辑、预览、字幕和 QA 都不属于本素材包流程。

完整可复用流程见 Skill 的 `references/material-pack-workflow.md`。
