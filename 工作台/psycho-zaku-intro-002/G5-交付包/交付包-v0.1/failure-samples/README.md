# 失败样本与处置

| 环节 | 真实失败 | 处置 |
|---|---|---|
| G4 字幕烧录 | 首轮渲染 N02/N04/N07 长 cue 溢出屏幕左右触边（本构建 libass 不自动断 CJK 长行；G3 布局校验器宽度模型假设任意字符可断，两者打架） | cue 内在标点处显式 \N 两行断行（文本逐字未动），重装配后 6 检查帧目视复验通过；缺陷入验收问题清单 |
| G4 字体预检 | 章节卡/封面首选 Hiragino Sans GB.ttc 被字形预检拒绝（cmap format 14 无法解析，宁拒不错） | 改 Songti.ttc（预检通过），复渲无豆腐块 |
| G4 装配帧率 | 首轮装配 fps=24 与计划 editPlan.fps=30 不一致 | 按 --fps 30 重装配（94.733s，帧取整 +13ms 合同内） |
