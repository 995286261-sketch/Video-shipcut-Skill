⑫｜找乐时长合同三层失守（真机全形态集齐，比 sinjuku 时代认知更深）｜
　(a) **API 参数无声失效**：`music_search_freesound.py` 把 `min_duration/max_duration` 作为查询参数发给 Freesound 文本检索端点，服务端不识别、静默忽略——11-19 三轮实证：terms-file 轮声明 `mode=hard, appliedMinSec=100` 而池内含 11.688s/28.5s/39.7s 曲（ffprobe 与 API duration 字段吻合，排除预览截短因素）；
　(b) **清单申报不实**：候选清单 `durationFilter` 照抄请求参数申报 hard，与池内实况矛盾——申报层与执行层脱节（同族案=connector v0.13.1 申报歪形）；
　(c) **shortfall 标注只在兜底路径**：`durationShortfall` 标记仅在 soft-fallback 轮生成，hard 轮短轨无标记，卡片层失去"短于目标"的机器提示；
　(d) **登记件无时长字段**：合同 ⑫ 说"用登记件里 trackDurationMs 机器比对 G0 目标下限"，但 `music_register_candidate.py` 登记件不产任何时长字段（decodeProbe 同跑已握 ffprobe 时长而未取）——编排比对只能借分析报告/池 probe 数字，合同字段缺机械来源；
　(e) **`--tags` AND 语义零命中无提示**：两轮 0 candidates 0 excluded（status 仍 completed），检索饿死与标签合取过严不分｜期望：时长过滤真实生效或如实申报未生效；短轨一律带 shortfall 标记；登记件带 trackDurationMs；零命中给出放宽建议；实际：以上全部缺席，bgm-choice 前编排人工时长比对成为唯一防线｜**中（供给合同层，四处独立缺陷同编号归案）**｜11-19 G1 找乐十一轮检索实录（候选清单 11 份在案）

⑬｜署名文本凭记忆默写导致登记件初版著录作者错误｜编排手敲 `--attribution` 时把 686768 作者写成记忆中的名字，检索件 attributionText 权威值实为「"Catchy Synthwave tune" by Robhog (https://creativecommons.org/licenses/by/4.0/)」；第二次登记逐字取自检索件字段修正｜期望：attribution/license 等合同字段一律从机器检索件逐字取用（申报合同机器生成同律），禁手敲默写；实际：登记件同名覆盖、初版错误未在盘上留痕（错误只存在于会话记录）——留痕缺失本身也是形态｜轻→**中风险敞口**（登记源头若错，v1.35.4 封包闸认的也是错的权威文本）｜11-19 G1 登记两连发实录；改进候选=登记脚本接受 `--attribution-from <检索件>` 直取字段（只记不修）

⑭｜distribution 受控词表两层不同步 + 音频许可读错层（G1 approve 熔断真案，含活体实验）｜
　(a) **入口宽、判定严**：`init --distribution` 接受任意自由文本（本次编排把用户卡片逐字 token「not_for_distribution，内部留存」转写成了散文「仅内部留存」），而永久闸 `validate_distribution_rights` 按"不在内向词表 {internal_test, local_only, not_for_distribution} 即按对外处理"——用户明示内部留存的片子被静默判成"对外分发"，approve 被永久闸拦（错误快照在案：`许可 '' 未清权 × 对外分发（'仅内部留存'）`）；
　(b) **许可字段读错层（活体实验实锤）**：实验性把 distribution 置 `bilibili_external` 后 approve，仍报 `许可 '' 未清权`——引擎读 asset 顶层 licenseType（恒空、material_pack schema 无此层），不读 `bgmRegistration.licenseType`（登记层真实值 cc-by）——后果=任何真·对外场景下所有已登记音乐恒被误报未清权（过拦方向，安全侧但账目不实；banshee/sinjuku 等 internal_test 项目提前 return 从未暴露）；
　处置留痕（如实申报绕行）：state.distribution 手工改回用户卡片逐字确认过的规范 token `not_for_distribution`（G0 九问卡操作区默认行原文「默认 not_for_distribution，内部留存」+用户"全部按建议授权"，非 AI 新裁决）；(b) 只记不修｜**中（合同词表闸缺位 + 判定层字段错位；(a) 属编排转写手误与引擎无入口校验共犯）**｜11-19 G1 approve 三拍实录（拦→实验→复通全链留证）
