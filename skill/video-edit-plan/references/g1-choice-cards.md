# G1 创作方向选择卡与自动回显

G1 继承 G0 已收集的信息（受众、平台、风格、BGM），只补充 G0 没问的：**标题、叙事角度、事实主张、表达边界**。

## 推荐纪律（模型自主，不设 harness）

每生成一组候选（标题、叙事角度等），模型必须基于当次素材与参考分析**自主推荐其中一项**，附一句话理由；推荐是模型的自由判断，不预设评分规则或固定 harness。**自 2026-09-11 用户定案（单卡模式）起，推荐即默认项：标题、叙事角度不再独立停靠提问，Agent 预选后连同【默认=推荐｜理由】并入 G1 最终回显卡；用户否决哪条，只重出哪条的候选。**用户永远可否决或另选；`directionChoice.source` 如实记录是采纳推荐默认（`agent_recommendation`）还是用户自选/另写（`custom`），审批记录写"用户验收推荐默认项"，不得写成"用户选择"。

## 固定交互（单卡模式下：候选生成规则不变，呈报方式并入最终回显）

### 1. 标题（2-3 个候选）

Agent 基于素材包内容和 G0 摘要，提供 2-3 个标题候选。每个候选标注类型：
- `editorial_expression`：编辑表达（主观观点）
- `factual_claim`：事实主张（需要证据支撑）
- `mixed`：混合

用户选一个，或自己写。

### 2. 叙事角度（三选一 + 自定义）

基于项目类型和素材，Agent 推荐 3 个叙事角度，第 4 个固定为"自定义"。

形式：角度名 + 一句话描述 + 适配风险

例如独角兽高达项目可推荐：
1. **机体科普 + 剧情背景**：以设定和变身机制为主线，建立"最特别的高达"认知。风险：注意不要剧透。
2. **视觉盛宴 + 情感共鸣**：画面冲击为主，配合史诗感叙事。风险：弱化科普性。
3. **对比评测 + 玩家视角**：以"为什么是巅峰"为切入点。风险：需要更多事实依据。
4. **自定义角度**（自己填写）

### 3. 事实主张（需要证据支撑）

列出视频中要陈述的关键事实，标注是否有素材包内的证据支撑：
- `supported`：有证据（说明书、官网、截图等）
- `pending`：待补事实（需要在简报中明确标注）

### 4. 表达边界

- 禁用表达：不能说什么、不能出现什么
- 剧透范围：可以剧透到什么程度
- 必须出现的信息：品牌、Logo、Slogan 等

```text
## ✅ 下一步操作（单卡模式）

1. 卡上各决策点均已给出**默认预选+理由**；逐条扫一眼。
2. 否决哪条说哪条（如"标题改 B""事实②补…"），只重跑该环节并重新出卡。
3. 无异议回复精确口令 `确认 G1` 锁定方向（含 BGM 槽状态如实呈报；pending 槽由状态机在 G2 前兜底）。

> 💡 示例回复："确认 G1"，或"角度改 3，其余按默认，确认 G1"（后者需先重出角度候选并再次回显，方向未定不得直接批）。
```

自动回显用于发现遗漏，**不是** G1 人工审批。方向简报、主张/表达边界和固定方向卡必须先完成并登记为机器可验证的 G1 门禁收据；仅当用户精确回复 `确认 G1` 时，状态机才写入已确认方向简报并放行 G2。
