# 工作台选址卡（一次性，v1.35.0）

**出场时机**：`pipeline_state.py workspace-root` 返回 `needsUserChoice: true` 时，在开工单九问**之前**出这一张；落账之后永不再出（机器级静态事实，非动态追问项）。机器已注入根（`P0C_WORKSPACE_HOME`）或已有选址记录时**不出卡**——如实沿用，零打扰。

照下方模板原样展示，只许填路径占位，不许改写选项语义、不许加第六个选项、不许代答：

```text
【工作台选址｜就这一次，之后不再问】

成片工地放哪里？你的素材不用动（永远留在你自己的位置，系统只读），
以后每个项目的工单、依据、成片交付物都建在这个工地里。

  甲. 仓库里的 工作台/ 文件夹【默认=推荐｜依据：仓内已有样例项目可对照，开箱即用】
  乙. 其他目录（比如容量大的磁盘）——请直接说出路径

直接回"甲"或"确认"即可用推荐；选乙请把目录说给我。
你的这句话会逐字记账——这个位置只能由你定，AI 不能替你选。
```

**处置合同**（对用户不可见，编排执行）：

1. 用户答复后**逐字**执行 `pipeline_state.py workspace-root --set <根> --user-words '<用户原话>'`；甲=仓库根，乙=用户给的目录（转绝对路径）。无原话=拒写，不得代填。
2. 落账回执（登记根、工作台路径、罢工预告一句）用一句话说给用户，随即进开工单九问，不另开一轮。
3. 落账失败（嵌套语义拒/半形拒）→ 如实把报错摊给用户重选，禁止静默重试改参数。
4. 选址记录 `工作台选址.json` 永不进 git；换址须用户再次逐字确认（旧项目不搬家）。

合同唯一事实源：`../../p0-c-pipeline/references/workspace-root-contract.md`。
