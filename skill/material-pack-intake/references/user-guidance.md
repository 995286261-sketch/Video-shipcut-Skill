# 用户引导话术与顺序

> 每个新项目先展示 `g0-start-form.md` 的**核心五问**；尤其要让用户明确选择 BGM 是已提供、后续选择还是不用。不得把 BGM 当成用户没提就默认没有的可选项。

For conflicts with older guidance, follow `g0-policy.md`.

一次只推进一个阶段。用户可以随时暂停或补充，不因缺少可选项而阻塞。

## 1. 核心五问（必填）

先展示开工单的核心五问：

> 1. 做什么内容？给谁看？
> 2. 发哪个平台？
> 3. 素材在哪？
> 4. 想要什么感觉？
> 5. 需要背景音乐吗？

接受自然语言回答，不要求技术字段。根据平台自动推导画幅和时长建议。

## 2. 收素材 + 按需追问

看到素材文件夹后，列出文件清单，并按需追问：

- **品牌资产**：如果用户提到公司/产品名 → "有 Logo、色值、字体要求吗？"
- **禁用内容**：如果涉及竞品、敏感话题 → "有什么不能说或不能出现的吗？"
- **授权范围**：如果用户没明确 → "这个片子是内部用还是可以对外发布？"
- **参考素材分类**：如果素材文件夹里有多个视频 → "这些哪些是素材，哪些是风格参考？"
- **配音需求**：如果需要旁白 → "用自己录的、AI 配音、还是不要旁白？"

将回答整理进 `01_需求说明.md` 和 `04_授权说明.md`。没有事实依据时明确登记"事实依据不足"，不要补写事实。

## 3. 资料清单回显（必须）

整理完成后，**必须**向用户展示资料清单，格式如下：

```text
【资料清单】

✅ 已收到：
- 原始素材：X 个视频（文件名列表）
- 事实依据：X 个文档
- 风格参考：X 个视频
- 品牌资产：Logo、色值等
- BGM：文件名（授权说明）

❓ 待确认：
- （列出还未明确的项）

📋 项目信息：
- 平台：XX（推导出的画幅和时长建议）
- 风格：（从用户回答提炼的关键词）
- BGM：已提供 / 待补 / 不用

请确认以上信息，或告诉我要补充/修改什么。
```

用户确认后才执行 `register` 和 `validate`。

## 4. 完成反馈

运行 `register` 和 `validate` 后只报告：素材包路径、文件清单、必填项状态、可选项状态、哈希登记结果和 `material-pack.json` 路径。不要在本 Skill 中开始转写、脚本或剪辑。
