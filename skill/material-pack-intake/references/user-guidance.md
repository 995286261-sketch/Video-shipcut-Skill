# 用户引导话术与顺序

> 每个新项目先展示 `g0-start-form.md` 的**开工单九问**（一卡问完）；尤其要让用户明确选择 BGM 是已提供、后续选择还是不用。不得把 BGM 当成用户没提就默认没有的可选项。

For conflicts with older guidance, follow `g0-policy.md`.

一次只推进一个阶段。用户可以随时暂停或补充，不因缺少可选项而阻塞。

## 1. 开工单九问（必填，一卡问完）

先展示开工单的九问（2026-10-09 重构：原核心五问 + 每项目必问的配音/品牌/流向/审批方式并入同卡，不再分两张卡让用户停两次）：

> 1. 做什么内容？给谁看？
> 2. 发哪个平台？
> 3. 素材在哪？
> 4. 想要什么感觉？（A 用几个词描述／B 给一支参考视频"像它那样剪"／C 从以前的成片挑一支模仿——三选一即可，详见开工单）
> 5. 需要背景音乐吗？
> 6. 要旁白配音吗？（自录／AI＋语言／不要）
> 7. 有品牌素材吗？（有给路径；没有填"无"——不代填、不沿用旧项目）
> 8. 片子做完后的去向？（内部留存／对外发布——这是授权边界，与第 2 问制式分开登记）
> 9. 本项目审批方式？（人工确认＝默认／自动确认＝需 G0 收尾逐条拍板预授权清单落策略文件）

接受自然语言回答，不要求技术字段。根据平台自动推导画幅和时长建议。

## 2. 收素材 + 冲突插问

看到素材文件夹后，列出文件清单。九问已把固定项一次问完；**只有回答互相冲突或分类不明时才当场插问**，例如：

- **禁用内容**：涉及竞品、敏感话题 → "有什么不能说或不能出现的吗？"
- **参考素材分类**：素材文件夹里有多个视频 → "这些哪些是素材，哪些是风格参考？"
- **自带音乐逐首授权**：第 5 问选 A → 每首单独确认使用范围与清权状态
- **第 2 问与第 8 问冲突**：说了平台却选内部留存 → 确认平台只是制式要求

插问问一次记一次，不得把插问养成第二张固定卡。将回答整理进 `01_需求说明.md` 和 `04_授权说明.md`。没有事实依据时明确登记"事实依据不足"，不要补写事实。

## 3. 资料清单回显（必须）

整理完成后，**必须**向用户展示资料清单，格式如下：

```text
【资料清单】

✅ 已收到：
- 原始素材：X 个视频（文件名列表）
- 事实依据：X 个文档
- 风格参考：X 个视频
- 品牌资产：Logo、色值等
- BGM：文件名（授权说明）

❓ 待确认：
- （列出还未明确的项）

📋 项目信息：
- 平台：XX（推导出的画幅和时长建议）
- 风格：（从用户回答提炼的关键词）
- BGM：已提供 / 待补 / 不用

请确认以上信息，或告诉我要补充/修改什么。
```

用户确认后才执行 `register` 和 `validate`。

## 4. 完成反馈

运行 `register` 和 `validate` 后只报告：素材包路径、文件清单、必填项状态、可选项状态、哈希登记结果和 `material-pack.json` 路径。不要在本 Skill 中开始转写、脚本或剪辑。
