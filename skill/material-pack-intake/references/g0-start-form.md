# G0 视频项目开工单

每个新项目必须先展示这张开工单。用户只需回答 5 个核心问题，不需要准备技术文件或时间码。

## 核心五问（必填）

```text
【G0 视频项目开工单】

1. 做什么内容？给谁看？
   例："产品宣传片，给潜在客户看" / "vlog，给粉丝看"

2. 发哪个平台？（可多选）
   抖音 / 快手 / B 站 / 微信视频号 / YouTube / 其他：___

3. 素材在哪？
   给个文件夹路径，或者告诉我大概有什么（视频/图片/文档/录音）

4. 想要什么感觉？
   有参考视频/博主吗？或者用几个词描述（如"科技感""温馨""快节奏"）

5. 需要背景音乐吗？
   A. 有自己的音乐（给我文件或路径）
   B. 没有，你来配 / 后续从音乐库选
   C. 不用 BGM
```

## 追问项（根据回答动态问）

Agent 在看到素材或收到回答后，按需追问：

- **品牌资产**：如果用户提到公司/产品名 → 追问"有 Logo、色值、字体要求吗？"
- **禁用内容**：如果涉及竞品、敏感话题 → 追问"有什么不能说或不能出现的吗？"
- **授权范围**：如果用户没明确 → 追问"这个片子是内部用还是可以对外发布？"
- **参考素材分类**：如果素材文件夹里有多个视频 → 追问"这些哪些是素材，哪些是风格参考？"
- **配音需求**：如果需要旁白 → 追问"用自己录的、AI 配音、还是不要旁白？"

## 资料清单回显

收完素材并整理后，**必须**向用户展示资料清单确认。所有产物路径必须写成可点击的 Markdown 超链接 `[文件名](相对路径)`，让用户能直接点开查看。

```text
【资料清单】

✅ 已收到：
- 原始素材：
  - [uc-p1.mp4](工作区/素材包/<projectId>/02_原始素材/uc-p1.mp4)
  - [uc-p2.mp4](工作区/素材包/<projectId>/02_原始素材/uc-p2.mp4)
- 事实依据：[产品说明书.pdf](工作区/素材包/<projectId>/03_事实依据/产品说明书.pdf)
- 风格参考：[apple-keynote-2024.mp4](工作区/素材包/<projectId>/05_风格参考/apple-keynote-2024.mp4)
- 品牌资产：[logo.png](工作区/素材包/<projectId>/06_品牌资产/logo.png)、色值 #007AFF
- BGM：[background-music.mp3](工作区/素材包/<projectId>/07_授权音频/background-music.mp3)（授权：本项目可用）

❓ 待确认：
- 授权范围：你说是"给客户看"，具体是仅内部演示还是可以对外的宣传片？
- 配音：还没确定，需要旁白吗？

📋 项目信息：
- 平台：抖音（竖版 9:16，建议 30-60 秒）
- 风格：科技感、简洁（参考 [apple-keynote-2024.mp4](工作区/素材包/<projectId>/05_风格参考/apple-keynote-2024.mp4)）
- BGM：已提供

请确认以上信息，或告诉我要补充/修改什么。
```

用户确认后，才执行 `register` 和 `validate`，标记素材包完成。

## Agent rules

1. **不要一次丢出 13 项表格**。先问核心五问，其他的看到素材后再追问。
2. **接受模糊回答**：用户说"就像那种科技感的产品展示"，agent 应该理解为风格关键词"科技感"，不需要用户自己总结。
3. **平台自动推导**：
   - 抖音/快手 → 竖版 9:16，15-60 秒
   - B 站 → 横版 16:9，3-10 分钟
   - 微信视频号 → 竖版 9:16 或横版 16:9，1-3 分钟
   - YouTube → 横版 16:9，5-15 分钟
4. **BGM 不得默认成"无"**。必须记录 A、B 或 C；B 表示 `BGM 待补`，后续 G1 与 G3 都要提示。
5. **授权不明时**记录"待确认"，默认不得对外发布。
6. **资料清单必须回显**：让用户看到 agent 整理了什么，有没有遗漏或分类错误。
