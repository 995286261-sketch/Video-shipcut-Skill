# G0 视频项目开工单

每个新项目必须先展示这张开工单。**一卡问完（九问），一次收齐**——用户不需要准备技术文件或时间码，也不应该为同一个 G0 停两次。固定追问项（配音、品牌、流向、审批方式）自 2026-10-09 起并入本卡，不再作为第二张动态卡；只有回答互相冲突或素材分类不明时才当场插问（见下"插问"节）。

## 开工单九问（必填，一卡问完）

```text
【G0 视频项目开工单】

1. 做什么内容？给谁看？
   例："产品宣传片，给潜在客户看" / "vlog，给粉丝看"

2. 发哪个平台？（可多选）
   抖音 / 快手 / B 站 / 微信视频号 / YouTube / 其他：___

3. 素材在哪？
   给个文件夹路径，或者告诉我大概有什么（视频/图片/文档/录音）

4. 想要什么感觉？（三种给法任选一种即可）
   A. 用几个词描述：如"科技感""温馨""快节奏"
   B. 给一支参考视频：发个你满意的视频路径或文件，"像它那样剪"——我们会先分析它的节奏和转场，照着那个感觉来
   C. 从你以前的成片里挑一支：说名字或路径，我们照着它模仿
   （B/C 的视频只当风格参考来分析，不会把它的画面剪进你的成片）

5. 需要背景音乐吗？
   A. 有自己的音乐（给我文件或路径）
   B. 没有，你来配 —— 到 G1 定完主题后，我们会给你一张检索词卡和几张候选歌的试听件，你挑一首；挑中的歌要经官方渠道拿到整轨并登记，才能进成片
      找歌来源跟片子去向走：**对外发布的片子只从 Freesound 版权可查的音乐库自动检索**（CC0/CC-BY，可商用、来源可审计）；**个人/内部用途默认从网易云全曲库找试听件供你选型**。G1 末的确认卡上会标明用的哪条通道，你可以切换
      （顺便问一句：对音乐有没有什么偏好？随口说说就行，**不要求必答**——我们本来就会按素材主题去找，有你的意向只是锦上添花）
   C. 不用 BGM

6. 要旁白配音吗？
   A. 自己录（给我音频文件路径）
   B. AI 配音（说明语言即可；音色选择到 G2 的试听卡再定，这里不用选）
   C. 不要旁白，纯字幕/音乐

7. 有品牌素材吗？（Logo、色值、字体、片尾标版）
   有就给路径或说明；没有填"无"。**不代填、不从旧项目沿用**——每个项目都要在场确认一次。

8. 片子做完后的去向？（这是授权边界，和第 2 问的"制式"是两回事）
   A. 内部留存/试看，不对外发布
   B. 对外发布（按第 2 问的平台真发出去）
   注意：对外发布会抬高清权要求——BGM 必须是"已清权/本项目可用"状态才能进对外成片；素材本身的版权也照此登记。

9. 本项目审批方式？
   A. 人工确认：每个节点停下等你口令（默认）
   B. 自动确认：闸和回显卡一个不少（每节点照出），批准由你现场拍板的**策略预授权清单**代替；信任类事项没有预授权就停下等你，三类事项（未清权×对外发布、授权不明×对外发布、人工背书断言）永远停下
   没填默认 A，不得替用户选 B。选 B 时 G0 收尾会给你预授权草案卡逐条确认，落成策略文件后才 init（connector 场景由输入规格携带）。
```

## 插问（只在冲突时问，不是固定第二段）

回答互相矛盾、或看到素材后分类不明时，才当场插问：

- **禁用内容**：涉及竞品、敏感话题 → "有什么不能说或不能出现的吗？"
- **参考素材分类**：素材文件夹里有多个视频 → "这些哪些是素材，哪些是风格参考？"
- **自带音乐逐首授权**：第 5 问选 A → 每首单独确认"这首允许用在哪、清权状态"
- **第 2 问与第 8 问冲突**：说了平台却选内部留存 → 确认平台只是制式要求
- 其余新发现的缺口：问到补上为止，问一次记一次，不复发成模板卡

收完素材并整理后，**必须**向用户展示资料清单确认。所有产物路径必须写成可点击的 Markdown 超链接 `[文件名](相对路径)`，让用户能直接点开查看。

```text
【资料清单】

✅ 已收到：
- 原始素材：
  - [uc-p1.mp4](工作台/<projectId>/G0-素材包/02_原始素材/uc-p1.mp4)
  - [uc-p2.mp4](工作台/<projectId>/G0-素材包/02_原始素材/uc-p2.mp4)

- 品牌资产：[logo.png](工作台/<projectId>/G0-素材包/06_品牌资产/logo.png)、色值 #007AFF

- 授权范围：你说是"给客户看"，具体是仅内部演示还是可以对外的宣传片？

📋 项目信息：
- 平台：抖音（竖版 9:16，建议 30-60 秒）
- 风格：科技感、简洁（参考 [apple-keynote-2024.mp4](工作台/<projectId>/G0-素材包/05_风格参考/apple-keynote-2024.mp4)）

  （BGM 选的是"你来配"时此行如实写：`待找乐（G1 末检索：<对外=Freesound 清权库 / 个人=网易云>，通道可在卡片上切换）`；选"不用"写 `不用 BGM`——照实转述，G0 不做任何音乐事务）
```

用户确认后，才执行 `register` 和 `validate`，标记素材包完成。

## Agent rules

1. **不要一次丢出 13 项表格**。固定项就一卡九问，问完收齐；其余只在回答冲突时插问（见"插问"节），不得把插问养成第二张固定卡。
2. **接受模糊回答**：用户说"就像那种科技感的产品展示"，agent 应该理解为风格关键词"科技感"，不需要用户自己总结。
3. **平台自动推导**：
   - 抖音/快手 → 竖版 9:16，15-60 秒
   - B 站 → 横版 16:9，3-10 分钟
   - 微信视频号 → 竖版 9:16 或横版 16:9，1-3 分钟
   - YouTube → 横版 16:9，5-15 分钟
4. **BGM 不得默认成"无"**。必须记录 A、B 或 C。**G0 专员只做声明与登记，不处理任何音乐事务**：选 B 时把槽如实落进素材包（用户如有偏好，原话记入 `BGM preference:` 行——可选输入，没有就留空，不得替用户编造）；槽的提醒由 `pipeline_state.py status` 从状态读出。**找歌发生在 G1 末**（主题产出后由编排调用 music-expert：检索词卡 → 候选试听 → 用户挑曲 → 官方渠道取得整轨并登记 → `bgm-choice` 翻槽），G2/G3 批准前槽必须已清——这些是 G1 与编排层的事，G0 卡片只如实转述，不代为执行。
5. **授权不明时**记录"待确认"，默认不得对外发布。
6. **资料清单必须回显**：让用户看到 agent 整理了什么，有没有遗漏或分类错误。
