# P0-C 运行依赖与可移植性

Skill 文件本身不等于完整运行环境。把项目交给另一台电脑前，先运行各节点的本地检查；缺少依赖时应显示 `blocked` 和安装/配置说明，不得假设“当前电脑以前装过”即可复用。

## 必需工具

| 能力 | 用途 | 当前约定 | 是否随 Skill 打包 |
| --- | --- | --- | --- |
| Python 3.12 | 运行各节点脚本 | `P0C_PYTHON_HOME` | 可由接收方安装；不复制系统 Python |
| FFmpeg + FFprobe | 探测、切片、渲染、QA | `P0C_FFMPEG_HOME` | 可提供经过许可的便携包；否则由接收方安装 |
| Faster-Whisper 运行时 | G2 离线转写 | `P0C_FASTER_WHISPER_HOME` | 可随项目提供已审核运行时，但不自动下载 |
| Faster-Whisper 模型缓存 | G2 离线转写 | `P0C_FASTER_WHISPER_MODEL_HOME` | 不默认打包；体积和模型许可需单独确认 |
| 本地 TTS/配音来源 | G2 试听、G4 完整旁白 | 以实际可发现的本地来源为准 | 不假设存在；需登记来源和许可 |

## 可选工具

`.tools/crawl4ai` 是网页抓取辅助环境，不是六节点视频生产的必需依赖。Facebook、TikTok 等站点是否可访问仍受站点、账号、授权和网络边界约束；安装 Crawl4AI 不代表可以绕过这些限制。

## 交付给他人的规则

1. 随 Skill 发送本依赖说明和检查结果，不发送个人账号、Cookie、临时上传文件或未授权模型。
2. 可携带工具的版本、架构、来源、许可证和 SHA-256；不要只携带一个不明来源的压缩包。
3. 对大模型和 TTS 声音，优先让接收方按许可单独安装或提供路径；没有模型/声音时，G2 必须暂停，不得编造可用选项。
4. 运行环境检查通过后，才允许执行 G2 本地转写或 G4 渲染；源素材仍保持只读。

## 模型能力声明

Skill 不绑定具体模型，但各节点依赖特定能力。运行前检查能力是否可用：

| 节点 | 需要的能力 | 若无此能力的后果 |
|------|-----------|-----------------|
| G1 | 多模态识图 | 参考视频分析退化为人工描述，无法生成技术分析报告 |
| G2 | 离线转写 + 本地 TTS | 口播准备需人工介入或用户提供字幕文件 |
| G3 | 多模态识图（可选） | 视觉验证需用户逐帧确认，无法自动描述画面内容 |
| G4 | 视频渲染 | 无替代方案，此能力为必需 |

### 多模态识图能力说明

- **能力定义**：能理解图片内容，描述画面、识别文字、判断场景类型
- **实现方式**：由已配置且获准的多模态视觉分析适配器提供；可以是当前 Agent 原生视觉能力、本地模型或批准的托管端点。规范不绑定具体模型、厂商、API 或部署方式。
- **Token 消耗**：每次调用约 2500-5000 token；实际总量取决于用户确认的抽帧间隔和候选局部验证策略，15 秒仅为示例，不得作为固定门槛。
- **能力边界**：
  - ✅ 能识别"有机体出现"、"人物对话"、"文字内容"等通用场景
  - ⚠️ 无法可靠区分具体机体/角色类型（如独角兽 vs 刹帝利）
  - ❌ 无法真正理解视频，只能分析静态帧

### Agent 诚实声明原则

Agent 应如实声明自己的多模态能力：
- **有识图能力**：可自动分析参考视频和抽帧内容
- **无识图能力**：不得假装能"看"图片，应直接告知用户并采用人工确认流程
- **不确定**：先测试一张图片，根据结果决定是否继续自动分析

## 节点归属

- G0：登记语言、口音、声线偏好和 BGM，不要求用户准备技术安装包。
- G2：检查本地转写运行时和实际可用 TTS/配音来源；生成试听并确认口音。
- G3：只消费 G2 已确认的声音设定，不选择不存在的声音。
- G4：生成完整旁白、执行渲染，并记录实际使用的运行时/声音来源。
- G5：复核成片音频并在交付包记录依赖版本、声音来源和分发限制。
