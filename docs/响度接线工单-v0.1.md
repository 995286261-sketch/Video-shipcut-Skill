## 批一设计决定（如实落账）

- **不新建 G2 侧"手术刀"包装脚本**：跨专员握手既有形状＝编排层直接调专员 CLI 产物、节点脚本只消费+对账（transition/music 先例）。再包一层是假彻底+依赖面。
- 接线后**新项目**的 G2 决定必须 `schemaVersion: 0.2`；历史项目 0.1 决定不追溯（R3 政策延伸，completed 项目不重跑校验）。
- 披露数字逐字取自《响度-归一化计划》产物（`ceilingLufs`/`status`/`exits`），呈现层零算术；卡片措辞由 G2 专员按红线自主。
- **卡型定稿（09-28 用户点头"就这么改"）**：固定卡型入 g2-choice-cards §3.5、样式指南 v1.3、zaku 样例增第五节（`65eb85e`）；卡型全部示例数字=工作台 6 源实跑真实产物。
- **zaku G2 实测彩排（09-28 用户令拿工作台项目试）**：拿 zaku 真实口播素材（只读）走全套——龙天/亭婷两候选规划（均 blocked：−22.8/−17.1，系统声反而更接近目标=判词≠分级的活例）、出路卡逐字 exits、0.2 决定校验放行；**真案抓出专员相对路径缺陷**并当场修复（产物 source 改落解析后绝对路径，合同 §6 补注，36 例回归绿，`39d100c`）。zaku 正式项目目录与门禁未动，产物在全局 `WorkSpace/响度接线-G2实测-zaku-v0.1/`。
- **实跑坐实的常态事实**：工作台全部 TTS/系统声口播源线性归一化都够不到 −14（静段峰均比高，物理事实）——出路卡是常态、默认 A"先压缩"即当年 G4 实走链；−14 靠 dynamic 时代变增益救出的口径问题登记为**批三 G4 核心议题**（届时带方案来谈）。

## 批三设计决定（如实落账）

- **三口径怎么来的（对用户疑问"不会是随便挑的吧"的诚实回答）**：拍板前盘上有三个候选口径，差异是**处置时机与诚实度**，不是随意措辞——
  - **甲（沿用现状+记账）**：G4 继续单遍动态、只把读数写进记录，超差不拦。差别=最轻改动，但"目标档"沦为装饰：G2/G3 辛辛苦苦对账的 −14，机器渲出来的实际是"大概 −16 一带"，双式记账断在最后一跳。
  - **乙（一刀切硬闸 ±1 LU）**：任何计划超差即罢工。差别=最重，但彩排已证伪——工作台全部真 TTS 源都走 blocked 档动态落点（长天 −15.6），乙=一切真项目 G4 永久罢工，逼用户每次现场改目标档绕闸，闸越硬越假。
  - **丙（分档）＝推荐获准**：闸的严格度跟着**计划的物理承诺**走——ready 计划=专员用实测算过"线性够得着"的承诺，落点必准，超差=链漂移/静默回退=违规罢工；blocked 计划=专员已摊牌"线性到不了"，用户在选择卡上肉眼批准了让步出路，落点差距是**已知让步幅度**，机器职责=如实落账+摊开确认，不是假装能到。甲乙丙共同底线：数字不编、模式落账、换档必回 G2/G3。
- **超差语义彩排定标（先计划后修正，如实记录）**：工单行原文"偏差 >±1 LU = 罢工附三成因"未区分两档；真素材彩排第一轮就拦在长天 −15.6（超差 1.60 LU）——证实无差别硬闸=假闸。收口为 strict 分档：ready=罢工、blocked=disclosed-exceedance 落账+G4 回显第③节摊开（reviewNote 强制生成，永不静默）；TP 超上限+0.3 余量两档共同硬闸（限幅链路坏不是响度取舍）。此语义变更随本批写入合同 §8.3，非事后补叙事。
- **闸在渲染之前、量纲=纯口播**：预渲染把执行链单独跑在口播源上实测（链尾挂验收口径 ebur128，同一次运行收 loudnorm print_format=json stats）——主轨混 BGM 的读数≠纯口播（成因②），闸必须闸在各量纲上；主轨读数照常写入记录只做记账。
- **镜像走 prepare 透传（targetFps ⑧乙同型）**：`g4_prepare.py` 把 G3 包装决定 `packagingDecisions.loudnessTarget` 逐字抄进 manifest `loudnessTarget`，assemble 拿它对三口径——旧计划无该字段则镜像如实落 null，用 `--loudness-plan` 时缺镜像=罢工（不在 G4 猜默认）。
- **压缩链 TP/LRA 参数化**：`NARRATION_STANDARD_CHAIN` 常量原先硬编码 −1.5/9，批三改按 targetProfile 三参数展开（卡说 X 机器渲 X 覆盖动态档）；podcast 档彩排用例锁死该行为。
- **旧 `--normalize-narration-lufs` 与计划旗标二选一互斥**，仅留历史补跑（R3）；其 ">1.5 LU 记 note 不拦" 旧语义原样保留不动。
- **负向彩排实录**：①镜像改 −16 → "三口径对账"拦；②口播拷贝换字节 → "规划源对不上"拦（R2 同型）；③skill 头改外来 → 身份拦；④顺手实盘第一案=批二彩排计划（projectId zaku-g2-rehearsal）对真项目 manifest → "串项目"拦。全部 exit 2 拦在重渲染之前。
