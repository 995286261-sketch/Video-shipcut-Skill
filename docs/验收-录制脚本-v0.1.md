## 1. 主演项目选型（决定录制时长）

| 方案 | 素材 | 预计录制时长 | 说明 |
|---|---|---|---|
| A（推荐） | 1 个 ≤3 分钟单一主体视频 + 用户口述 3–5 句事实 | 60–90 分钟（渲染挂机可剪辑加速） | 全链真跑，每个门禁都有真实画面 |
| B | 直接展示 tiger-intro-001 封存产物 | 25–35 分钟 | 不重跑渲染，讲"已经发生过的事实"；适合时间紧张 |

方案 A 素材纪律：现场录制用的素材必须**授权明确**（自拍/无版权），避免 BGM 与肖像话题带偏验收主线；BGM 用「不用 BGM」或素材包内已清权件，把 §3-⑥ 的红牌演示交给展品（tiger 档案里现成的 3 条 uncleared 红灯 + LOW 边界告警）。

## 2. 六幕脚本（每幕=用户输入 → 屏幕应出现 → 镜头亮点）

### 第一幕 G0「把素材丢给对话」
- 用户只需说：`我要做一个介绍 X 的短视频，素材在这个目录`（AGENTS.md 自动路由，不点名 skill）。
- 屏幕：Agent 建 `工作台/<projectId>/`，跑 `material_pack.py validate`，缺口按模板逐项追问；授权/分发边界两问必须可见。
- 亮点台词：**"从这里开始，它没让我准备任何一个 JSON。"**
- 门禁：G0 回显卡 + `确认 G0`。

### 第二幕 G1「方向和找乐一起定」
- 用户答三件事：受众/用途、风格参照（可无）、BGM 意向（口头偏好即可）。
- 屏幕：方向简报 + BGM 检索词卡（默认预选＋依据两行）；查库先行——展示 `music_library.py list` 的红绿灯列。
- 亮点①：拿 tiger 展品跑 `music_library.py query`，让**分发边界红牌**（"仅限档案原项目，必须重新清权并登记"）进镜头——这是⑤修复的现场证据。
- 门禁：`确认 G1`。

### 第三幕 G2「证据和口播」
- 用户挑叙事角度（单卡，默认=推荐）；Agent 产事实清单+口播稿+配音简报。
- 亮点台词：**"每句话都能点回证据文件，编的话它会说不知道。"**
- 门禁：`确认 G2`（若 BGM 槽未清，这里会真实演示关单强制项）。

### 第四幕 G3「时间线，机器的归机器」
- 屏幕重点录两样：①镜头检测优先的探索抽帧（㉓方法论）；②每段"实际画面观察"三帧验证。
- 演示一次**故意投毒**（可录外准备）：把某段 `observedVisuals` 写成"希望出现 XX"，跑 `validate_g3_plan.py`，展示**一次报全**的 `errors[]` 批量清单（㉕）+ 评审期就拒 `mappingMode: sequence`（㉗）——"错要早报、全报，别等渲染完"。
- 门禁：`确认 G3`（口令嵌在句子里也有效——㉙新语义，口播一句"我确认G3，顺便把封面裁一下"）。

### 第五幕 G4「本地渲染，一条道走到哈希」
- 屏幕：`g4_prepare → g4_render → g4_validate → g4_assemble`，中段挂机可 8× 加速。
- 演示 `g4_prepare` 把 `--output-dir` 指错目录（`G4-随便名`）→ **当场 blocked**（㉚）：守卫不等关单。
- 如有单 face 字体则正常出字幕/章节卡；亮点台词：**"字体缺字它会拒绝开工，而不是渲完给你一片豆腐块。"**（㉛）
- 人工停靠：回放候选成片 → `确认 G4`。

### 第六幕 G5「交付包与审计链」
- 屏幕：`g5_build_delivery_manifest --bundle --evidence` → `g5_validate_delivery --media` → `g5_audit_bgm_chain`（12 项全绿，逐条 hash 回指素材包）。
- 人工停靠：真人看片 + 检查帧 → 「确认交付」或「逐条接受警告」两种语义各解释一句。
- 结尾镜头：打开封存的交付包目录 + `delivery-manifest.json` 与 `README.md`。

## 3. 建议拍进去的"能力边界"镜头（诚实即卖点）

1. 问一个素材里没有的问题 → Agent 答"无证据，不做推断"；
2. tiger 档案的 uncleared 试听件红牌（不得对外分发）；
3. 归档目录只读审计：翻 `pipeline-state.json` 说明"状态唯一事实源，归档不许救状态"。

## 4. 风险与补救

- 渲染失败/环境问题：NG 重录该幕即可，前幕门禁产物在盘上，从下一幕继续；
- 忘 export PATH：报错即镜头——`runtime-dependencies.md` 讲一句；
- 单条重录对照表：每幕屏幕出现的门禁收据文件名（`G?-门禁收据.json`）= 后期剪辑锚点。
